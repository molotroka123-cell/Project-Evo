# Технопарк `research_park`

**Эпоха 7 — Современность** · требует технологию: `mass_media`

---

## ИДЕЯ

Научный кластер современности: сам силён и делает сильнее всех учёных соседей. Кульминация линии «библиотека → школа → технопарк».

## ЛОГИКА

2.8 знания и +25% знанию в радиусе 4 — сильнейшая научная аура в игре. Технопарк, окружённый лабораториями, даёт больше, чем ИИ-центр.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
research_park: { name: 'Технопарк', cost: { stone: 150, steel: 100, gold: 120 }, workers: 5, out: { knowledge: 2.8 }, aura: { r: 4, knowledge: 1.25 }, req: 'mass_media' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
research_park: 7,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.knowledge. ОБЯЗАТЕЛЬНО учесть общий потолок аур знания, иначе кластер из четырёх зданий сломает темп эпох.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e7.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не выпускать без потолка. Это самая опасная петля из всех новых зданий.
