# Тотем `totem`

**Эпоха 0 — Каменный век** · требует технологию: `language`

---

## ИДЕЯ

Счастье, привязанное к месту. Не абстрактный «+3 всем», а «людям хорошо рядом с тотемом» — первый намёк на то, что у поселения есть центр.

## ЛОГИКА

+3 глобально и +2 жителям в радиусе 4. Дёшево, но не складывается: два тотема рядом дают +6 глобально, а не +4 локально дважды.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
totem: { name: 'Тотем', cost: { wood: 10 }, happy: 3, aura: { r: 4, happy: 2 }, req: 'language' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
totem: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.happy — новый ключ, требует ветки в применителе ауры. Считать по ЖИТЕЛЯМ в радиусе, а не по зданиям.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать спамом: ввести мягкий потолок — счастье от тотемов не больше +9 суммарно.
