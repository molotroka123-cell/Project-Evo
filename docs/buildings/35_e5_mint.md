# Монетный двор `mint`

**Эпоха 5 — Ренессанс** · требует технологию: `banking`

---

## ИДЕЯ

Деньги, которые надо чеканить из металла. Множитель с себестоимостью — редкость, и потому запоминается.

## ЛОГИКА

×1.2 ко всему золоту, но −0.4 камня в день. Банк даёт ×1.25 без расхода, зато монетный двор доступен раньше и дешевле.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
mint: { name: 'Монетный двор', cost: { stone: 90, gold: 100 }, goldMult: 1.2, consume: { stone: 0.4 }, req: 'banking' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
mint: 5,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** goldMult и consume уже читаются. Проверить, перемножаются ли goldMult банка и монетного двора, и ввести потолок.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e5.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не позволять цепочке банк+биржа+монетный двор дать ×1.95. Ввести общий потолок на goldMult.
