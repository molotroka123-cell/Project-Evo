# Железный горн `iron_forge`

**Эпоха 2 — Железный век** · требует технологию: `iron`

---

## ИДЕЯ

Первое здание, которое ЕСТ ресурс, чтобы работать. Учит, что производство имеет себестоимость, — и готовит к фабрике эпохи 6.

## ЛОГИКА

1.2 камня и +10% армии, но −0.5 дерева в день. При нехватке дерева горн становится обузой, и это правильно.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
iron_forge: { name: 'Железный горн', cost: { wood: 30, stone: 25 }, workers: 3, out: { stone: 1.2 }, consume: { wood: 0.5 }, armyMult: 1.1, aura: { r: 2, gather: 1.1 }, req: 'iron' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
iron_forge: 2,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** consume уже читается (factory). Проверить, ОСТАНАВЛИВАЕТСЯ ли здание при нехватке ресурса, или уводит склад в минус. Второе — баг, ловить тестом.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e2.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать ему работать бесплатно при пустом складе дерева.
