# Текстильная фабрика `textile_mill`

**Эпоха 6 — Индустриальная** · требует технологию: `corporations`

---

## ИДЕЯ

Массовое производство одежды: много денег, тяжёлый труд. Индустриальный ответ ткацкой из бронзового века — та давала счастье, эта отнимает.

## ЛОГИКА

2.5 золота — больше всех в эпохе, но −3 счастья. Зеркало ткацкой: тот же товар, обратный социальный знак.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
textile_mill: { name: 'Текстильная фабрика', cost: { wood: 100, stone: 120, gold: 80 }, workers: 6, out: { gold: 2.5 }, happy: -3, req: 'corporations' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
textile_mill: 6,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление. В описании прямо сослаться на ткацкую — игрок должен заметить рифму.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e6.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать больше 2.8 золота: биржа и банк должны остаться главными по деньгам.
