# Коптильня `smoke_house`

**Эпоха 0 — Каменный век** · требует технологию: `hunting`

---

## ИДЕЯ

Не добывает еду — СОХРАНЯЕТ её. Отвечает на настоящую боль ранней игры: летом склад полон и добыча уходит впустую, зимой пусто.

## ЛОГИКА

+150 к потолку еды. Это половина амбара за две трети цены, но доступна раньше (по hunting, не по pottery). Аура foodKeep — задел на порчу еды, если её введут; пока безвредна.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
smoke_house: { name: 'Коптильня', cost: { wood: 14 }, cap: { food: 150 }, winter: true, aura: { r: 2, foodKeep: 1.0 }, req: 'hunting' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
smoke_house: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** cap уже читается (granary). Аура foodKeep пока НЕ реализована — либо реализовать как «еда рядом не портится», либо УБРАТЬ из определения и не писать мёртвое поле. Второе честнее.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не добавлять поле, которое ничего не делает. Если механики порчи нет — выкинуть aura целиком.
