# Ветряная мельница `windmill`

**Эпоха 4 — Средневековье** · требует технологию: `machinery`

---

## ИДЕЯ

Вторая мельница — на холме, а не у воды. Разводит ландшафт: у реки одна, на возвышенности другая, и обе усиливают поля.

## ЛОГИКА

×1.4 фермам против ×1.5 у водяной мельницы, но needTile:6 (холм) вместо привязки к воде. Слабее и капризнее по месту.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
windmill: { name: 'Ветряная мельница', cost: { wood: 35, stone: 25 }, aura: { r: 3, farm: 1.4 }, needTile: 6, req: 'machinery' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
windmill: 4,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.farm уже реализована (mill). Ничего нового.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e4.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать двум мельницам складываться. Брать максимум, иначе поле в радиусе обеих даст ×2.1.
