# Гончарня `potter`

**Эпоха 1 — Бронзовый век** · требует технологию: `pottery`

---

## ИДЕЯ

Ремесло как источник денег и как усилитель складов. Первое здание, где производство и инфраструктура — одно и то же.

## ЛОГИКА

0.5 золота — половина рынка, но рынок требует trade, а гончарня доступна по pottery, то есть заметно раньше. Аура +20% к потолку складов в радиусе 3.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
potter: { name: 'Гончарня', cost: { wood: 18, stone: 8 }, workers: 2, out: { gold: 0.5 }, aura: { r: 3, cap: 1.2 }, req: 'pottery' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
potter: 1,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует тот же aura.cap, что и глиняный карьер. Реализовать один раз.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e1.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать больше 0.6 золота: ранние деньги ломают темп технологий.
