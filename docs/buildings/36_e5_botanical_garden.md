# Ботанический сад `botanical_garden`

**Эпоха 5 — Ренессанс** · требует технологию: `navigation`

---

## ИДЕЯ

Заморские растения: красиво, полезно полям, немного лечит. Награда за мореплавание, которую видно в городе.

## ЛОГИКА

+8 счастья, +15% фермам в радиусе 4 (радиус больше, чем у мельниц, множитель меньше), 0.2 медицины.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
botanical_garden: { name: 'Ботанический сад', cost: { wood: 70, gold: 50 }, workers: 2, happy: 8, aura: { r: 4, farm: 1.15 }, medicine: 0.2, req: 'navigation' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
botanical_garden: 5,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.farm — уже реализована.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e5.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не складывать с мельницами. Брать максимум из всех аур farm.
