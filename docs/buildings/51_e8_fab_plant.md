# Фабрика микросхем `fab_plant`

**Эпоха 8 — Информационная** · требует технологию: `robotics`

---

## ИДЕЯ

Превращает сталь в знание и деньги. Первое здание, переводящее материальный ресурс в нематериальный, — сама суть информационной эпохи.

## ЛОГИКА

2.5 знания и 1.5 золота за 1.0 стали в день. При нехватке стали останавливается — и вся цепочка робозавод→фабрика становится осмысленной.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
fab_plant: { name: 'Фабрика микросхем', cost: { steel: 250, gold: 200 }, workers: 3, out: { knowledge: 2.5, gold: 1.5 }, consume: { steel: 1.0 }, req: 'robotics' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
fab_plant: 8,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление. Проверить остановку при нехватке стали.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e8.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать работать без стали.
