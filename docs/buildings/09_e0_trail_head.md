# Тропа `trail_head`

**Эпоха 0 — Каменный век** · требует технологию: `null`

---

## ИДЕЯ

Расширяет рабочий радиус поселения. Даёт ответ на «вокруг всё выбрано» дешевле, чем переезд.

## ЛОГИКА

+1 к радиусу за 5 дерева. Радиус растёт линейно, площадь — квадратично, поэтому вторая и третья тропа дают всё больше. Нужен ПОТОЛОК: не больше +3 суммарно, иначе поселение поглотит карту.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
trail_head: { name: 'Тропа', cost: { wood: 5 }, radiusBonus: 1, req: null },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
trail_head: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** radiusBonus уже читается (train_station). Проверить, СКЛАДЫВАЕТСЯ ли он от нескольких зданий, и если да — ввести потолок в применителе.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Без потолка не выпускать. Это ровно та петля, которая обязана иметь предел.
