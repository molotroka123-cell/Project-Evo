# Глиняный карьер `clay_pit`

**Эпоха 0 — Каменный век** · требует технологию: `pottery`

---

## ИДЕЯ

Связывает добычу с хранением: глина идёт и на камень, и на посуду. Даёт повод ставить амбар рядом с карьером, а не в центре.

## ЛОГИКА

0.6 камня — вдвое хуже каменоломни, но на равнине (needTile:3), а не у холма. Аура +15% к потолку складов в радиусе 2 — вот ради чего строят.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
clay_pit: { name: 'Глиняный карьер', cost: { wood: 10 }, workers: 2, out: { stone: 0.6 }, needTile: 3, aura: { r: 2, cap: 1.15 }, req: 'pottery' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
clay_pit: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.cap — новый ключ. Применять к зданиям с полем cap в радиусе.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать ауре складываться сверх +30%.
