# Массив Дайсона `dyson_array`

**Эпоха 9 — Будущее** · требует технологию: `fusion`

---

## ИДЕЯ

Энергия звезды. Самое дорогое здание в игре и самый большой множитель промышленности — цель, ради которой копят всю последнюю эпоху.

## ЛОГИКА

industry ×2.0 против ×1.5 у термояда. unique. Стоит примерно как два термояда — и потому строится вместо, а не вместе.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
dyson_array: { name: 'Массив Дайсона', cost: { steel: 900, gold: 700 }, industry: 2.0, unique: true, req: 'fusion' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
dyson_array: 9,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление. Проверить общий потолок industry: цепочка Дайсон+термояд+АЭС не должна дать ×4.5.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e9.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не выпускать без общего потолка на industry.
