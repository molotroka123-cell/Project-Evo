# Академия художеств `art_academy`

**Эпоха 5 — Ренессанс** · требует технологию: `optics`

---

## ИДЕЯ

Искусство как государственная политика: делает людей и умнее, и довольнее. Ветка «культуры», которой в игре пока нет вовсе.

## ЛОГИКА

1.6 знания и +10 счастья, плюс +3 соседям. Обсерватория даёт 2.6 знания и ноль счастья — прямой размен науки на настроение.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
art_academy: { name: 'Академия художеств', cost: { stone: 100, gold: 70 }, workers: 3, out: { knowledge: 1.6 }, happy: 10, aura: { r: 3, happy: 3 }, req: 'optics' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
art_academy: 5,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.happy.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e5.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать её главным источником науки эпохи: обсерватория обязана остаться впереди.
