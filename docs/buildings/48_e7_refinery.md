# Нефтеперерабатывающий завод `refinery`

**Эпоха 7 — Современность** · требует технологию: `flight`

---

## ИДЕЯ

Пик грязной промышленности: много стали, много энергии, много вреда. Здание, вокруг которого никто не хочет жить.

## ЛОГИКА

2.5 стали и ×1.2 промышленности, но −6 счастья (сильнейший штраф в игре) и риск пожара.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
refinery: { name: 'НПЗ', cost: { stone: 220, steel: 140 }, workers: 5, out: { steel: 2.5 }, consume: { stone: 1.2 }, industry: 1.2, risk: 'fire', happy: -6, req: 'flight' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
refinery: 7,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует risk:"fire" (см. газовый завод). Реализовать ветку один раз на оба здания.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e7.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не смягчать штраф. Если игрок строит НПЗ без последствий — теряется весь смысл экологической цены.
