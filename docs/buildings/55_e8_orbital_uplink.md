# Орбитальная связь `orbital_uplink`

**Эпоха 8 — Информационная** · требует технологию: `internet`

---

## ИДЕЯ

Связь со всем миром: сильнейший торговый множитель и обзор половины карты. Одно на поселение.

## ЛОГИКА

caravanMult 2.5 — рекорд игры, +3 радиуса. unique:true, дорога.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
orbital_uplink: { name: 'Орбитальная связь', cost: { steel: 300, gold: 250 }, workers: 2, out: { knowledge: 2.0 }, caravanMult: 2.5, radiusBonus: 3, unique: true, req: 'internet' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
orbital_uplink: 8,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление. Учесть общий потолок caravanMult и радиуса.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e8.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не позволять перемножаться с аэропортом и вокзалом без потолка.
