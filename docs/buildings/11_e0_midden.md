# Мусорная куча `midden`

**Эпоха 0 — Каменный век** · требует технологию: `null`

---

## ИДЕЯ

Первое здание с ОТРИЦАТЕЛЬНЫМ эффектом. Даёт еду ценой недовольства — выбор отчаяния, который спасает от голодной смерти и наказывает, если оставить навсегда.

## ЛОГИКА

0.9 еды бесплатно, но −3 счастья. При голоде это спасение; при сытости — вредительство. Игрок обязан её СНОСИТЬ, когда кризис прошёл, — и это единственное здание, которое учит сносу.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
midden: { name: 'Мусорная куча', cost: {}, workers: 1, out: { food: 0.9 }, happy: -3, req: null },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
midden: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** happy с отрицательным значением уже поддержан? Проверить, что применитель счастья не отсекает отрицательные. Если отсекает — исправить, иначе всё здание бессмысленно.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать её выгодной постоянно. Если игрок держит мусорку всю партию — числа подобраны неверно.
