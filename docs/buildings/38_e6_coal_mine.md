# Угольная шахта `coal_mine`

**Эпоха 6 — Индустриальная** · требует технологию: `industrialization`

---

## ИДЕЯ

Топливо промышленности. Даёт много камня, усиливает заводы вокруг и портит воздух — вся индустриальная эпоха в одном здании.

## ЛОГИКА

2.0 камня (лучше шахты), +20% промышленности соседям, −3 счастья глобально. Первое здание, где выгода и вред очевидно связаны.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
coal_mine: { name: 'Угольная шахта', cost: { wood: 60, stone: 80 }, workers: 5, out: { stone: 2.0 }, aura: { r: 3, industry: 1.2 }, happy: -3, needTile: 6, req: 'industrialization' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
coal_mine: 6,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.industry — новый ключ. Применять к полю industry соседей (power_plant, npp).

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e6.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не убирать штраф счастья. Он и есть цена индустриализации.
