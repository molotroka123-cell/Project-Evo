# Караван-сарай `caravanserai`

**Эпоха 1 — Бронзовый век** · требует технологию: `trade`

---

## ИДЕЯ

Торговля как связь с соседями, а не как цифра. Даёт причину дружить с фракциями за десять эпох до дипломатии всерьёз.

## ЛОГИКА

caravanMult 1.3 — первый в игре (верфь эпохи 5 даёт 1.5). Ранний, слабый, но задаёт направление.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
caravanserai: { name: 'Караван-сарай', cost: { wood: 25, stone: 15 }, workers: 2, out: { gold: 0.6 }, caravanMult: 1.3, happy: 2, req: 'trade' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
caravanserai: 1,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** caravanMult уже читается (shipyard, train_station, airport). Проверить, перемножаются ли они, и ввести потолок.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e1.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать множители складываться без предела: три здания по 1.3 дадут ×2.2 и обвалят баланс караванов.
