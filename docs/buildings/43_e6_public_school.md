# Народная школа `public_school`

**Эпоха 6 — Индустриальная** · требует технологию: `sanitation`

---

## ИДЕЯ

Всеобщее образование: наука для всех, а не для избранных. Даёт и знание, и довольство — политическое здание по духу.

## ЛОГИКА

1.8 знания против 3 у лаборатории, но вдвое дешевле, плюс +6 счастья и аура знанию.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
public_school: { name: 'Народная школа', cost: { stone: 110, gold: 60 }, workers: 4, out: { knowledge: 1.8 }, happy: 6, aura: { r: 3, knowledge: 1.15 }, req: 'sanitation' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
public_school: 6,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.knowledge (см. библиотека).

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e6.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать аурам знания складываться сверх ×1.4 суммарно.
