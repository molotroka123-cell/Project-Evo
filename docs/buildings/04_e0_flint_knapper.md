# Кремнёвая мастерская `flint_knapper`

**Эпоха 0 — Каменный век** · требует технологию: `hunting`

---

## ИДЕЯ

Первое здание, которое НИЧЕГО не производит само, а усиливает соседей. Учит игрока думать о расстановке за десять эпох до районов.

## ЛОГИКА

+25% охоте в радиусе 3. Работает только с охотничьими стоянками — значит, стоянки надо ставить кучно, а не разбрасывать. Потолок естественный: одна мастерская на кластер, вторая перекрывается.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
flint_knapper: { name: 'Кремнёвая мастерская', cost: { wood: 8, stone: 4 }, aura: { r: 3, hunt: 1.25 }, req: 'hunting' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
flint_knapper: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** КЛЮЧЕВОЕ: ключ aura.hunt в коде НЕ СУЩЕСТВУЕТ — сейчас читаются только gather и farm (см. smithy, mill). Найти, где применяется aura, и добавить ветку hunt для зданий с out.food и req hunting. Тест обязан ловить, что аура НЕ действует за пределами r=3.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не складывать две ауры мультипликативно. Брать максимум, иначе четыре мастерские дадут ×2.4 и охота сломает экономику.
