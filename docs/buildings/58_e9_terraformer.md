# Терраформер `terraformer`

**Эпоха 9 — Будущее** · требует технологию: `fusion`

---

## ИДЕЯ

Переделка самой земли: радиус 8 — четверть поселения — и всё в нём родит вдвое лучше. Кульминация всей линии аур, начатой кремнёвой мастерской в каменном веке.

## ЛОГИКА

+60% фермам и +30% добыче в радиусе 8. Ест 1.5 стали. unique. Самая широкая аура в игре — и единственная, ради которой перестраивают город.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
terraformer: { name: 'Терраформер', cost: { steel: 800, gold: 600 }, workers: 4, consume: { steel: 1.5 }, aura: { r: 8, farm: 1.6, gather: 1.3 }, unique: true, req: 'fusion' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
terraformer: 9,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.farm и aura.gather. Проверить, что радиус 8 не роняет FPS: обход соседей на каждом здании — потенциально квадратичный. Кэшировать список соседей, а не считать каждый день.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e9.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не считать соседей заново каждый день без кэша. При 116 зданиях и радиусе 8 это заметная цена кадра.
