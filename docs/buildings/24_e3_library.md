# Библиотека `library`

**Эпоха 3 — Античность** · требует технологию: `writing`

---

## ИДЕЯ

Наука кучкуется. Библиотека рядом с академией и обсерваторией даёт научный квартал — самая узнаваемая идея Civ 6, переведённая напрямую.

## ЛОГИКА

1.0 знания и +20% знанию соседей в радиусе 3. Сама по себе слабее академии (1.2), но пара «библиотека+академия» даёт 1.0+1.44 против 2.4 у двух академий — почти столько же, но дешевле.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
library: { name: 'Библиотека', cost: { wood: 40, stone: 40 }, workers: 3, out: { knowledge: 1.0 }, aura: { r: 3, knowledge: 1.2 }, req: 'writing' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
library: 3,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.knowledge — новый ключ. Применять к out.knowledge соседей.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e3.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать ауре действовать на саму себя. Две библиотеки рядом не должны усиливать друг друга в петле.
