# Плац `drill_ground`

**Эпоха 2 — Железный век** · требует технологию: `warfare`

---

## ИДЕЯ

Военная застройка кучкуется: казарма, оружейная и плац рядом дают больше, чем те же три здания вразброс. Прямая цитата из районов Civ 6.

## ЛОГИКА

+20% к armyMult соседей в радиусе 3 — не к армии напрямую, а к зданиям, которые её усиливают. Значит, ценность плаца зависит от того, что рядом.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
drill_ground: { name: 'Плац', cost: { stone: 20 }, aura: { r: 3, army: 1.2 }, req: 'warfare' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
drill_ground: 2,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.army — новый ключ. Применять к armyMult соседних зданий, НЕ к армии напрямую (иначе двойной счёт).

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e2.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не применять ауру к самой армии. Только к соседним зданиям с armyMult.
