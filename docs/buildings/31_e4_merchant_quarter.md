# Купеческий квартал `merchant_quarter`

**Эпоха 4 — Средневековье** · требует технологию: `banking`

---

## ИДЕЯ

Торговый район: сам зарабатывает и усиливает соседей-торговцев. Вторая половина идеи районов после научного квартала.

## ЛОГИКА

1.8 золота и +20% золоту соседей в радиусе 2 — радиус меньше, чем у форума, но множитель больше. Требует плотной застройки.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
merchant_quarter: { name: 'Купеческий квартал', cost: { wood: 60, stone: 50, gold: 40 }, workers: 4, out: { gold: 1.8 }, aura: { r: 2, gold: 1.2 }, req: 'banking' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
merchant_quarter: 4,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.gold (см. форум). Реализовать один раз.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e4.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

Не перемножать с аурой форума. При наложении брать максимум.
