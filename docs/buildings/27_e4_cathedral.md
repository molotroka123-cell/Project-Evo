# Собор `cathedral`

**Эпоха 4 — Средневековье** · требует технологию: `theology`

---

## ИДЕЯ

Вершина религиозной ветки: дорогой, единственный, виден издалека. Дает игроку долгосрочную цель на всю эпоху.

## ЛОГИКА

+16 счастья — вдвое больше храма. unique:true. Стоит как замок, и потому строится вместо него, а не вместе.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
cathedral: { name: 'Собор', cost: { stone: 200, gold: 100 }, workers: 3, happy: 16, out: { knowledge: 0.8 }, unique: true, req: 'theology' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
cathedral: 4,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление. Убедиться, что рендер даёт собору заметный силуэт, иначе главная награда эпохи невидима.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e4.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать дешевле замка: они обязаны конкурировать за один и тот же камень.
