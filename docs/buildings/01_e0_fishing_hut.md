# Рыбацкая хижина `fishing_hut`

**Эпоха 0 — Каменный век** · требует технологию: `null`

---

## ИДЕЯ

Первый повод уйти от костра к воде. Даёт еду ЗИМОЙ, когда собиратели и ферма стоят, — и потому меняет выбор места для поселения ещё в первый день.

## ЛОГИКА

2.0 еды против 2.2 у собирателей: летом хуже, зимой единственный источник. coast:true жёстко привязывает к берегу — это и есть решение. Потолка не нужно: ограничение и так в длине берега.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
fishing_hut: { name: 'Рыбацкая хижина', cost: { wood: 8 }, workers: 2, out: { food: 2.0 }, coast: true, winter: true, req: null },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
fishing_hut: 0,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Добавить в BUILDINGS. Проверить, что флаг coast уже читается размещением (его использует port) — новой логики не требуется.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e0.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать её лучше собирателей летом. Смысл в сезонной страховке, а не в замене.
