# Форум `forum`

**Эпоха 3 — Античность** · требует технологию: `aesthetics`

---

## ИДЕЯ

Центр города: деньги, настроение и усиление торговых соседей. Место, вокруг которого хочется строить.

## ЛОГИКА

1.0 золота, +5 счастья, +15% золоту соседей в радиусе 3. Форум с тремя рынками вокруг заметно лучше форума в поле.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
forum: { name: 'Форум', cost: { stone: 70, gold: 20 }, workers: 2, out: { gold: 1.0 }, happy: 5, aura: { r: 3, gold: 1.15 }, req: 'aesthetics' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
forum: 3,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** aura.gold — новый ключ. Применять к out.gold соседей.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e3.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не усиливать зданиями с goldMult (банк, биржа) — иначе множители перемножатся и вырастут лавиной.
