# Святилище `shrine`

**Эпоха 1 — Бронзовый век** · требует технологию: `masonry`

---

## ИДЕЯ

Предок храма. Даёт понять, что вера в этой игре — механика счастья и знания, а не декорация, задолго до появления теологии.

## ЛОГИКА

+4 глобально, +2 в радиусе, 0.4 знания. Храм эпохи 3 даёт +8 — святилище ровно вдвое слабее, и это читается как прогресс.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
shrine: { name: 'Святилище', cost: { stone: 20 }, workers: 1, out: { knowledge: 0.4 }, happy: 4, aura: { r: 4, happy: 2 }, req: 'masonry' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
shrine: 1,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Использует aura.happy (см. тотем).

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e1.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать святилище и храм взаимозаменяемыми: храм обязан быть заметно сильнее.
