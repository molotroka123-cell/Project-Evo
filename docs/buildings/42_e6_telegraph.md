# Телеграф `telegraph`

**Эпоха 6 — Индустриальная** · требует технологию: `railroads`

---

## ИДЕЯ

Связь ускоряет и науку, и торговлю, и разведку. Здание-инфраструктура, чья польза заметна не сразу.

## ЛОГИКА

1.2 знания, +40% караванам, +1 радиус. Ни в чём не лучший, но единственный, кто закрывает три направления сразу.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
telegraph: { name: 'Телеграф', cost: { stone: 90, steel: 40, gold: 70 }, workers: 2, out: { knowledge: 1.2 }, caravanMult: 1.4, radiusBonus: 1, req: 'railroads' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
telegraph: 6,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление, все поля уже читаются.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e6.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не давать больше 1.5 caravanMult: вокзал (×2) обязан остаться главным.
