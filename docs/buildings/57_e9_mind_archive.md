# Архив разума `mind_archive`

**Эпоха 9 — Будущее** · требует технологию: `singularity`

---

## ИДЕЯ

Все знания человечества в одном месте. Финальное научное здание, открывающее прямой путь к Шпилю.

## ЛОГИКА

14 знания — почти вдвое больше ИИ-центра, при одном рабочем. unique. Дорог настолько, что строится в самом конце.

## ИСПОЛНЕНИЕ

Добавить в `app/src/core/data.js`, в объект `BUILDINGS`:

```js
mind_archive: { name: 'Архив разума', cost: { steel: 700, gold: 800 }, workers: 1, out: { knowledge: 14 }, happy: 10, unique: true, req: 'singularity' },
```

И в `BUILDING_ERA_IDX` (или туда, где в этом дереве живёт привязка к эпохе):

```js
mind_archive: 9,
```

Описание `desc` пиши сам, одной строкой, на русском, по правилу проекта:
говори игроку, ЧТО ЭТО ДАЁТ и КАКОЙ ЦЕНОЙ, а не пересказывай поля.

**Что править в коде:** Прямое добавление.

**Тест.** Заведи проверку в существующем наборе по этой эпохе (или создай
`app/tests/test-buildings-e9.mjs`). Тест обязан:
1. падать на дереве БЕЗ этого здания и проходить с ним — проверь оба
   состояния сам, прежде чем сдавать;
2. проверять числа, а не факт существования ключа;
3. если у здания есть аура, отдельно проверять, что за пределами радиуса
   она НЕ действует.

## ЧЕГО НЕ ДЕЛАТЬ

Не делать доступным раньше singularity: иначе последняя эпоха схлопнется в один ход.
