# Diplomacy Design — Project Evolution

## Принцип

Дипломатия — продолжение личностей лидеров и интересов обществ, а не набор фиксированных опций.

## Инструменты

Переговоры · Торговые договоры · Посольства · Угрозы · Союзы · Дань · Династические браки · Обмен технологиями · Культурное влияние · Санкции · Мировой конгресс · Мирные договоры · Шпионаж

## Модель отношений

Многомерная, не «+/- отношение»:

- **Доверие** (история выполнения договоров)
- **Страх** (военный потенциал)
- **Зависимость** (торговля, ресурсы)
- **Культурная близость** (язык, религия)
- **Личные отношения лидеров** (дружба, обиды, родство)

## Эмерджентные сценарии

- Холодная война: гонка без прямого конфликта — санкции, прокси, шпионаж.
- Религиозные расколы → коалиции по конфессиям.
- Мировой конгресс (поздние эпохи): резолюции, санкции большинством.

## Шпионаж

Агенты = NPC с легендой. Операции: разведка, кража технологий, саботаж, подстрекательство, пропаганда. Провал → дипломатический кризис.

## Взаимодействие

- Экономика: санкции реально режут маршруты; дань = ресурсный поток.
- Война: мирные договоры с условиями (территории, репарации, браки).
- Культура: мягкая сила меняет лояльность чужих городов.

## Edge cases

- «Вечный союзник» — дрейф интересов со временем.
- Игрок-изоляционист — мир не должен стоять на месте вокруг него.

## Открытые вопросы

- Формат мирового конгресса: голосования в реальном времени или сессии?
- Видимость информации: что игрок знает о переговорах ИИ-ИИ?
