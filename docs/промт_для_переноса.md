# Промт для Ox Alpha (или любой модели с большим окном)

Копировать целиком. Ниже — три варианта в порядке убывания разумности.
Под каждым сказано, чего он стоит и что вернёт.

---

## Вариант A — рекомендую: спроектировать перенос, не писать код вслепую

Модель с окном в 1M прочитает весь репозиторий за один заход — это её главное
преимущество, и тратить его надо на понимание, а не на генерацию 23 тысяч строк
C#, которые никто не проверит.

```
Ты — ведущий инженер, которому поручено перенести готовую браузерную стратегию
на Unity (C#). Проект приложен целиком.

СНАЧАЛА ПРОЧИТАЙ docs/ПЕРЕНОС_В_ДВИЖОК.md — там карта кода, контракт связей и
список ловушек, на которых перенос ломается молча.

Твоя задача на этот заход — НЕ писать игру. Задача — выдать план, по которому
её напишут без сюрпризов. Верни:

1. РАЗБОР ЯДРА. По каждому из 30 файлов app/src/core/: что он делает, от чего
   зависит, какие у него входы и выходы. Найди зависимости, которые в
   документе не описаны.

2. ПОРЯДОК ПЕРЕНОСА. Топологическая сортировка по зависимостям: что можно
   писать параллельно, что строго последовательно. Для каждого шага — как
   проверить, что он верен, ДО того как появится графика.

3. МЕСТА, ГДЕ C# ВЕДЁТ СЕБЯ ИНАЧЕ. Пройди по коду и найди все места, где
   перенос «в лоб» даст другое число: целочисленное переполнение, знаковые
   сдвиги, порядок обхода словарей, float против double, приведение типов,
   поведение при делении на ноль. По каждому — конкретный файл, строка и что
   написать вместо.

4. ЧТО НЕ ПЕРЕНОСИТЬ. Найди в ядре то, что существует только из-за особенностей
   браузера или Canvas 2D и в Unity не нужно.

5. ОЦЕНКА. Сколько строк C# выйдет, сколько это человеко-дней, и где самый
   большой риск.

Отвечай по-русски. Не пиши код, кроме коротких примеров в пункте 3.
Если чего-то в коде не понял — так и скажи, не додумывай.
```

**Что вернёт:** план, по которому дальше можно работать хоть с этой моделью,
хоть с другой, хоть руками. Проверяемо, полезно, не выбрасывается.

## Вариант B — если всё-таки нужен код: одна система за заход

Просить «перепиши всю игру» бессмысленно: получишь 23 тысячи строк, которые
невозможно проверить, и первая же ошибка в генераторе сделает всё остальное
мусором. Поэтому — по одному файлу, начиная с фундамента.

```
Ты переносишь браузерную стратегию на Unity (C#). Проект приложен.

Прочитай docs/ПЕРЕНОС_В_ДВИЖОК.md, раздел 2 — про детерминизм — обязательно.

Перенеси на C# РОВНО ОДИН файл: app/src/core/rng.js

Требования:
· Класс Rng с методами Next, Range, Int, Pick, Chance, GetState, SetState —
  один в один по смыслу с оригиналом.
· Класс Noise2D с fBm, включая тасование таблицы перестановок тем же
  генератором и в том же порядке.
· Всё в double. Никаких float.
· Целочисленная арифметика unchecked, беззнаковые сдвиги на uint.
· Отдельным файлом — тест NUnit, который сверяет вывод с контрольными
  значениями из раздела 2.3 документа. Тест обязан падать, если хоть одно
  число разошлось.

Отвечай по-русски. Сначала код, потом — список мест, где ты сомневался,
и почему выбрал такой вариант.
```

Дальше тот же промт для `data.js`, потом `world.js`, и так по порядку из
раздела 6 документа. Каждый заход проверяется тестом, прежде чем идти дальше.

Не подыгрывай. Если Unity здесь избыточен — скажи прямо.

## Как отдать модели код

Через веб-интерфейс OpenRouter приложить репозиторий целиком не выйдет.
Варианты:

1. **Ссылка на GitHub.** Ветка уже запушена:
   `molotroka123-cell/Project-Evo`, ветка `claude/unreal-rise-of-nations-game-vzzl9h`.
   Многие модели умеют читать публичные репозитории по ссылке.

2. **Собрать один текстовый файл.** В корне проекта:
   ```
   node tools/source-dump.mjs          # ядро + этот документ
   ```
   Получится `frontier-source-default.txt`: 35 файлов, 23 681 строка,
   1.3 МБ, примерно **448 тыс. токенов** — в окно 1M влезает с большим
   запасом. Это ровно то, что нужно приложить.

   Другие наборы:
   ```
   node tools/source-dump.mjs core     # только ядро, 441 тыс. токенов
   node tools/source-dump.mjs all      # + рендер, интерфейс, тесты
   ```
   Набор `all` — это 1.42 млн токенов, и в окно 1M он **не влезает**.
   Инструмент об этом честно пишет в выводе. Для переноса он и не нужен:
   рисование выбрасывается, а тесты переписываются на C#.

   (`tools/pack.mjs` собирает ZIP для передачи человеку — модели он
   бесполезен, она архив не откроет.)

3. **По частям.** Для варианта B хватит одного файла за раз: `rng.js` — это
   51 строка.
