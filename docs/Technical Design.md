# Technical Design — Project Evolution

## 1. Стек

- Unreal Engine 5.5+, C++20
- Nanite / Lumen / Virtual Shadow Maps / World Partition
- ECS-подобная модель данных для симуляции (Mass Entity или собственный SoA-слой)
- JSON + Lua для data-driven контента и модов

## 2. Архитектура: разделение симуляции и рендера

```
┌─────────────────────────────────────────┐
│  Presentation (UE5: рендер, звук, UI)   │
├─────────────────────────────────────────┤
│  Simulation Core (чистый C++, без UE)   │
│  - ECS, tick-based, детерминизм*        │
│  - LOD-симуляция, фоновые потоки        │
├─────────────────────────────────────────┤
│  Data Layer (JSON defs, Lua scripts)    │
└─────────────────────────────────────────┘
```

Симуляция не зависит от движка: тестируется headless, повторяется, профилируется отдельно.

## 3. Масштабирование NPC

| Режим | NPC | Метод |
|---|---|---|
| Full sim | до ~1 000 | индивидуальный tick: память, отношения, планы |
| LOD sim | до ~100 000 | агрегированные «домохозяйства», обновление по бюджету кадра |
| Background | миллионы | статистические модели (рождаемость, миграция) |

Переход NPC между режимами — бесшовный, с сохранением состояния.

## 4. Многопоточность

- Job-система поверх UE TaskGraph.
- Симуляция мира, ИИ, экономика — независимые очереди задач.
- Chunk streaming карты (World Partition) + streaming данных симуляции.

## 5. Сохранения

- Снапшот ECS-миров в бинарном виде + инкрементальные дельты.
- Фоновая запись, авто-сейвы, rollback, replay (лог решений + детерминизм).
- Цель: миллионы объектов, автосейв < 1 с блокировки кадра.

## 6. Процедурная генерация

Терраформирование: континенты, реки, климатические пояса, биомы, вулканы.
Seed-driven, детерминированная, редактируемая в Tools.

## 7. Сборка и CI

- Windows-приоритет; GitHub Actions: compile + smoke-test.
- Артефакты: `Builds/ProjectEvolution-<version>.zip`.
- Позже: Perforce для бинарных ассетов.

## 8. Производительность — бюджеты

- 60 FPS при 10 000 видимых NPC на mid-high PC.
- Симуляция 100k NPC ≤ 8 мс/тик (LOD).
- GPU: Nanite-кластеры, HLOD для городов.

## 9. Риски

- Связность систем → экспоненциальная сложность отладки. Митигация: событийная шина + replay.
- Детерминизм и float-расхождения между платформами.
- Память при миллионах объектов в сейвах.
