# Game Design Document — Project Evolution

## 1. Видение

Лучшая sandbox-стратегия про цивилизацию: от каменного века до ближайшего будущего. Игра не рассказывает историю — она её генерирует. Каждое прохождение уникально.

## 2. Эпохи (скоп v1)

Каменный век → Бронзовый → Железный → Античность → Средневековье → Ренессанс → Индустрия → Современность → Ближайшее будущее. Космос — позже, архитектура расширяема.

## 3. Игровые циклы

### Core loop (минута)
Наблюдай → принимай решение → симуляция реагирует → следствия порождают новые истории.

### Mid loop (час)
Рост поселения: еда → жильё → работа → знания → технология → новые возможности → новые проблемы.

### Long loop (сессия/кампания)
Племя → деревня → город → государство → империя. Смена эпох через эмерджентные открытия.

## 4. Ключевые фантазии игрока

- «Я вырастил цивилизацию из ничего».
- «Эта история произошла только у меня».
- «Мир живёт и без меня».

## 5. Основные системы

| Система | Суть | Взаимодействия |
|---|---|---|
| NPC-симуляция | Каждый житель — личность с памятью и целями | Экономика, политика, религия, война |
| Знания | Технологии открываются людьми и распространяются | Торговля, война, книги, университеты |
| Строительство | Модульные здания, физическое возведение | Экономика, пожары, разрушения |
| Экономика | Спрос/предложение, инфляция, торговые пути | Налоги, гильдии, кризисы |
| Политика | Формы правления возникают из общества | Революции, реформы, легитимность |
| Война | От дубин до дронов; логистика и мораль | Экономика, дипломатия, технологии |
| Дипломатия | Переговоры, союзы, санкции, конгресс | Торговля, культура, шпионаж |
| Религия | Возникает естественно: пророки, схизмы | Политика, война, культура |
| Мир | Процедурный, климат, катастрофы | Ресурсы, миграции, сельское хозяйство |

## 6. Сложность

Никаких бонусов врагам. Сложность = умнее ИИ, агрессивнее дипломатия, жёстче ресурсное давление.
