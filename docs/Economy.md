# Economy Design — Project Evolution

## Принцип

Полностью симулируемая экономика: ни один товар не появляется из ниоткуда и не исчезает в никуда. Цены рождаются из спроса и предложения.

## Эволюция экономики по эпохам

| Эпоха | Формы |
|---|---|
| Каменный век | Натуральный обмен, дар/долг |
| Бронза/Железо | Товарные деньги, караваны |
| Античность/Средневековье | Монета, налоги, гильдии, рынки |
| Ренессанс | Банки, векселя, компании |
| Индустрия | Корпорации, биржа, кредит |
| Современность+ | Глобальная торговля, кризисы, цифровые валюты |

## Ядро симуляции

- **Агенты:** домохозяйства, мастерские, торговцы, государство.
- **Рынки:** локальные (поселение) → региональные → мировые; цены по избытку/дефициту.
- **Логистика:** караваны, корабли, дороги — товар существует физически в пути.
- **Деньги:** эмиссия, инфляция, дефляция, дебасмент монеты.
- **Тень:** чёрные рынки, контрабанда (возникают при запретах и высоких налогах).

## Циклы

Бум → перегрев → кризис → рецессия → восстановление. Причины — эндогенные (перепроизводство, неурожай, война, паника на бирже).

## Взаимодействие с системами

- Война: разрушает маршруты, повышает цены, создаёт военный кейнсианский бум.
- Религия: запреты (усурия), праздники (спрос), храмы (накопление богатства).
- Политика: налоги, монополии, национализация → легитимность и недовольство.
- Мир: неурожай/наводнение → шок предложения.

## Эксплойты и защита

- Скупка всего ресурса (corner the market) → антимонопольное недовольство, контрабанда, новые источники.
- Спам караванами → издержки логистики, разбойники, дорожная инфраструктура.
