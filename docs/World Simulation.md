# World Simulation — Project Evolution

## Генерация мира

Seed-driven, детерминированная: континенты, острова, горы, реки, климатические пояса, биомы (леса, пустыни, вулканы, океаны). Текторно-плиточная модель + процедурная детализация при стриминге.

## Живые системы

| Система | Динамика |
|---|---|
| Климат и погода | Фронты, дожди, засухи, штормы; влияет на урожай, мораль, болезни |
| Сезоны | 4 сезона; зима = стресс логистики и еды |
| День/ночь | Цикл активности NPC, стража, ночные преступления |
| Гидрология | Реки текут, разливаются; наводнения меняют почву |
| Леса | Деревья растут, стареют, падают; леса экспандируют/исчезают |
| Животные | Популяции, миграции, хищник-жертва; истребимы охотой |
| Ресурсы | Конечны; возобновляемые (лес) и исчерпаемые (руды) |
| Катастрофы | Землетрясения, извержения, эпидемии, метеоры (редко, с предзнаменованиями) |

## Экосистемные петли

Перелесозаготовка → эрозия → падение урожайности → голод → миграция. Игрок видит цепочки причин и следствий, а не «события из таблицы».

## LOD-симуляция мира

- Активные чанки: полная динамика.
- Фоновые чанки: статистические модели с теми же законами; при активации — «догонка» состояния.

## Взаимодействие

- Экономика: погода → цены на еду; катастрофы → страховые/религиозные реакции.
- Война: переправы, наводнения как оружие, зимние кампании.
- Культура: катастрофы → религиозные интерпретации, культы, мифы.
