# Арт-партия 1 — 20 ассетов, сгенерировано и ждёт вшивания

Модель `nano_banana_pro` (Google — **не ставит водяных знаков**, в отличие
от того генератора, чей знак «AI生成» вшит в нынешний `victory.jpg`).
Разрешение 2048×2048 (2k). Потрачено 40 кредитов Higgsfield.

Все промты взяты из готового `tools/art/prompts.json` — стиль совпадает с
тем, что уже задумано проектом, а не выдуман заново.

## Как вшить (конвейер уже написан, ничего изобретать не надо)

1. Скачать генерации из Higgsfield.
2. Разложить по именам из таблицы ниже в `art/raw/`.
3. `node tools/art/cutout.mjs` — вырежет пурпурный хромакей (#FF00FF) и
   разложит спрайты.
4. `npm run build`.

Фон у всех иконок и зданий — сплошной `#FF00FF` именно затем, чтобы
`cutout.mjs` сработал без ручной обводки.

## Важное про иконки в меню

Аудит нашёл: плитки построек показывают **системные эмодзи** (🔥, синий
кран, розовая больница) внутри графитовой военной рамки. Это и есть та
деталь, из-за которой игра выглядит на десять долларов.

При этом настоящие спрайты зданий существуют и хороши
(`shots/preview_buildings16.png`). Правка бесплатна: в
`app/src/ui/building_drawer.js` таблица `ICONS` (строка 102) отдаёт эмодзи
через `iconOf(id)` — заменить на отрисовку спрайта из `sprites.js`.
Сгенерированный арт делает то же самое ещё лучше, но даже без него
эмодзи в плитках менять надо.
