# ФРОНТИР — архитектурный аудит (фаза 1)

Дата: 31.07.2026. Ветка `claude/unreal-rise-of-nations-game-vzzl9h`.
Аудит сделан чтением кода и замерами исполнения, а не по описаниям.

---

## 1. Технологический стек

| Что | Чем |
|---|---|
| Язык | Ванильный JavaScript, ES-модули. TypeScript **отсутствует** |
| Сборка | esbuild → один самодостаточный `frontier.html` (1.6 МБ) |
| Рендер | Canvas 2D, ручной цикл `requestAnimationFrame` |
| Состояние | Класс `Simulation` — единственный источник правды |
| Сохранения | localStorage + экспорт/импорт файла, `SAVE_VERSION = 3` |
| Тесты | Голые node-скрипты, без фреймворка. 17 файлов, 419 проверок |
| Зависимости | Одна: `esbuild`. Playwright — только для скриншотов |
| Запуск | Двойной клик по `frontier.html`, работает офлайн из `file://` |

Стек выбран сознательно: заказчику нужна игра, запускающаяся без установки.
Ни Unity, ни Unreal, ни React в проекте нет и не планируется.

## 4. Десять главных рисков

Отсортированы по тому, насколько дорого чинить позже.

**Р1. 8 500 строк мёртвого кода.** Тесты зелёные, игрок не видит ничего.
Каждый день промедления — рост расхождения между модулем и изменившимся ядром.

**Р2. Нет контракта данных.** 14 модулей независимо изобрели свои формы города,
фракции, персонажа, события. `empire.js` и `civ_ai.js` оба заводят поселения —
по разным правилам. При подключении они подерутся.

**Р3. `simulation.js` — 1 704 строки бога-объекта.** Ресурсы, жители, стройка,
эпохи, дипломатия, рейды, рынок, события в одном классе. Каждое подключение
дописывает сюда ещё, класс растёт нелинейно.

**Р4. Сейвы не готовы к росту.** `SAVE_VERSION = 3`, миграция есть только для
v1→v3. Поле `sys` я добавил с обратной совместимостью, но версию не поднял —
следующий, кто добавит поле, сломает чужие сейвы молча.

**Р5. Игрок не видит причин.** В HUD ноль индикаторов прироста ресурсов
(проверено грепом). Еда падает — почему, сколько осталось дней, что делать —
не сказано нигде.

**Р6. Знания копятся в никуда.** Замер: 3 000 дней без вмешательства игрока →
1 799 знаний, **0 изученных технологий, эпоха 0**. Ничто не подсказывает, что
знания надо тратить. Это и есть «непонятный игровой цикл» из твоего списка.

**Р7. Люди — кружочки.** Главная визуальная претензия заказчика. Жители
рисуются примитивом в `renderer.js:215`.

**Р8. Один путь победы.** `victory()` вызывается только из `tickSpire` при
5-й стадии Шпиля. Ни научной, ни культурной, ни экономической победы нет.

**Р9. Нет команд запуска.** `package.json` без `scripts`. Как собрать, как
прогнать тесты — знание живёт в голове, а не в репозитории.

**Р10. Ресурсов шесть и они плоские.** `{food, wood, stone, steel, gold,
knowledge}`. Нет энергии (нужна для индустрии и будущего), нет влияния
(нужно для дипломатии и территорий) — а обе эпохи в игре уже есть.

## 5. Предлагаемые общие контракты

Мастер-промт просит 19 интерфейсов. Честная оценка: под текущую архитектуру
нужно **пять**, остальные — преждевременное обобщение под игру, которой нет.

```js
// 1. Контракт подсистемы. Всё, что подключается к ядру, выглядит одинаково.
//    Уже реализован в systems/integrate.js для зимы и границ — расширяем его,
//    а не изобретаем заново.
{
  create(ctx)          -> state      // ctx: {world, rng, day}
  onNewDay(state, ctx) -> report     // раз в игровые сутки
  tick(state, ctx, dt) -> void       // опционально, для непрерывных процессов
  serialize(state)     -> plain      // только JSON-совместимое
  deserialize(data)    -> state
}

// 2. Отчёт подсистемы. Модуль НЕ меняет мир — возвращает, что случилось.
//    Применяет integrate.js. Так модуль остаётся тестируемым в одиночку.
{ res: {…дельты}, log: [{text, type}], deaths: [pid], flags: {…} }

// 3. Место на карте. Общее для empire, worldsites, front, borders.
{ id, x, y, owner, kind, name }

// 4. Действующее лицо. Общее для politics, civ_ai, front, population.
{ id, name, role, traits[], loyalty, age, memories[] }

// 5. Событие летописи. Структурные данные, текст генерируется при показе.
{ id, day, era, category, severity, actors[], place, meta }
```

Правило, которое уже работает и его надо закрепить: **весь рандом через
`rng` из ядра.** `Math.random` запрещён — он ломает воспроизводимость сейвов.
Проверено грепом по всем 14 модулям: нарушений ноль.

## 6. Карта владения (кто что трогает)

Ключевое правило против конфликтов: **у каждого файла один владелец.**

| Агент | Владеет | Читает, но не пишет |
|---|---|---|
| Интегратор (я) | `systems/integrate.js`, `simulation.js` | всё |
| Графика | `render/*` | `core/*` |
| Экономика | `systems/{economy,production}.js` | `data.js` |
| Политика | `systems/{politics,laws}.js` | `population.js` |
| Война | `systems/{army,front,borders}.js` | `world.js` |
| Мир | `systems/{worldgen2,worldsites,empire}.js` | `world.js` |
| Соседи | `systems/{civ_ai,diplomacy_ext}.js` | `data.js` |
| Интерфейс | `ui/*` | `core/*` |

`app/src/core/data.js` — общая таблица, правит **только интегратор**:
туда лезут все, и это единственный реальный источник конфликтов.

## 7. Порядок работ

Сначала подключение написанного, потом новое. Каждый шаг оставляет игру
играбельной и заканчивается прогоном всех тестов.

**Очередь 1 — сделать написанное работающим (это и есть твои пункты 1–5).**

1. `civ_ai` — соседи оживают. Самая заметная перемена за наименьшие деньги.
2. `production` + `economy` — ресурсы становятся связанными (твой пункт 3).
3. `population` — жители обретают профессии и судьбу.
4. HUD: прирост в минуту, свободные рабочие, причина нехватки (пункт 4).
5. Подсказки: знания копятся — предложить технологию (лечит Р6, пункт 2).

**Очередь 2 — карта и война.**

6. `worldgen2` + `worldsites` — биомы, реки, залежи.
7. `army` + `front` — бои на карте, снабжение, знаменосцы.
8. `empire` — несколько городов.
9. `diplomacy_ext` — союзы, право прохода.

**Очередь 3 — политика и смыслы.**

10. `politics` + `laws` — формы правления, сословия, стабильность.
11. Летопись — структурные события вместо строк (уже есть `chronicle`, надо
    переделать на данные).
12. Альтернативные победы — минимум четыре пути.
13. Экология, шпионаж, персонажи-лидеры.

**Параллельно и независимо:** графика — своя папка, свой агент, ничьих файлов
не касается. Запущена уже сейчас.
