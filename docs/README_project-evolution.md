# PROJECT EVOLUTION

**Жанр:** Sandbox Strategy / City Builder / Civilisation Simulator / Colony Sim / RTS
**Движок:** Unreal Engine 5 (C++)
**Платформа:** Windows (приоритет), далее Mac / Linux / Console
**Целевой визуал:** Manor Lords, Kingdom Come: Deliverance 2 — фотореализм, Nanite, Lumen, динамические сезоны и погода. Без пиксель-арта и стилизации.

## Главная идея

Игрок начинает с первобытного племени в каменном веке — ничего не существует:
ни построек, ни технологий, ни государства, ни письменности, ни религии.
Всё открывается естественным путём из симуляции. Цивилизация эволюционирует до далёкого будущего:

**Каменный век → Бронзовый век → Железный век → Античность → Средневековье → Ренессанс → Индустриальная революция → Современность → Ближайшее будущее**

## Ключевые принципы

- Игрока никогда не принуждают — всё возникает из симуляции (emergent gameplay).
- Каждая механика взаимодействует с каждой другой механикой.
- Технологии не разблокируются таймерами — они открываются персонажами и распространяются между поселениями.
- Каждый NPC живой: имя, семья, память, страхи, амбиции, лояльность.
- Мир процедурный и живой: климат, миграции животных, наводнения, катастрофы.
- ИИ не читерит — видит только доступную информацию.
- Игра должна сама создавать истории; каждое прохождение уникально.
- Цивилизация должна существовать и через 5000 симулируемых лет.

## Как играть

1. Склонировать репозиторий.
2. Открыть `ProjectEvolution.uproject` в Unreal Engine 5.
3. Нажать **Play** — игра запускается в редакторе.
4. Позже — готовые `.exe` сборки из `Builds/`.
