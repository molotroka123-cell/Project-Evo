# AI Design — Project Evolution

## Принципы

- ИИ не читерит: видит только доступную информацию (fog of knowledge, не fog of war).
- Планирует годами вперёд, учится на неудачах.
- Личности лидеров → разное поведение. Минимум скриптов.

## Архитектура (гибрид)

1. **Utility AI** — оценка действий по взвешенным кривым (голод, страх, амбиции).
2. **GOAP** — целеполагание NPC и поселений («построить мельницу» → план действий).
3. **Behavior Trees** — тактический уровень (бой, ремесло, рутина).
4. **HTN (для лидеров/государств)** — стратегическое планирование на годы.

## Персона NPC

- Черты: амбиции, честность, агрессия, любопытство, лояльность (Big-Five-подобные оси).
- Память: события с эмоциональной окраской, затухание со временем.
- Отношения: граф семья/друзья/враги + репутация.
- Следствия: предательство, революция, легенды — эмерджентно.

## ИИ государств

- Лидер = NPC со своей личностью → политика государства эмерджентна.
- Оценка угроз, окна возможностей, коалиции.
- Обучение: простой experience buffer («прошлая война провалилась из-за логистики»).

## Диффузия знаний

Открытие — вероятностное событие, зависящее от наблюдений конкретного NPC.
Распространение: торговля, пленные учёные, книги, университеты, война (ускоряет), мир (ускоряет науку).

## Edge cases

- Петля «мести» между NPC — нужны механики прощения/забвения.
- Лидер-психопат уничтожает своё государство — допустимо, но с рамками «выживание режима».
- Стохастика открытий: защита от «вечного застоя» и от «мгновенной техногонки».
