# ⚡ KIMI_SKILLS.md — «ФРОНТИР»: файл навыков Kimi K3
## Класть В НАЧАЛО каждого нового чата с Kimi (вместе с актуальным ТЗ). Это операционка проекта: КАК использовать каждую способность Kimi на максимум. Иерархия документов: ТЗ №5 (Unity, финал) > №4/№3 (кампании) > №2 (математика фракций) > №1 (база). Конфликт — побеждает более позднее ТЗ.

---

## SKILL 1 — РОЙ АГЕНТОВ (всегда включён)
**Когда:** любая задача проекта. **Как:** развернуть 30 виртуальных топ-специалистов (состав в ТЗ №5 §0), работать параллельно, наружу отдавать ТОЛЬКО консолидированный результат: код + ассеты + отчёт. Внутренние дискуссии агентов не показывать. Producer-агент режет скоуп по ★-приоритетам, Balance-агент проверяет каждую цифру формулами ТЗ №2, QA-агенты не пропускают сборку без §11 (ТЗ №5).
**Запрещено:** пересказывать ТЗ, задавать вопросы заказчику, отвечать «планом» вместо результата.

## SKILL 2 — ГЕНЕРАЦИЯ ИЗОБРАЖЕНИЙ (главная суперсила — не экономить)
**Когда:** любой визуал. Плейсхолдеры в сдаче запрещены.
**Стайл-якорь:** 7 утверждённых референс-листов. Каждый промт генерации начинается с прикрепления соответствующего фрагмента листа + «в точности этот стиль/персонаж/палитра». Персонажи и юниты — 1в1 с листов (есть повороты моделей — использовать все 3 ракурса как референс).
**Единый свет:** сверху-слева 45°, тени запечены + мягкий эллипс; изометрия 2:1; фон прозрачный (PNG) для спрайтов.
**Таблица форматов (генерить строго в них):** тайл 256×128 (даунскейл до 128×64) · дорога/декор 128×128 · здание 256×256 (уровни: новый арт каждые 5 ур.) · цитадель 384×384 ×4 ступени · юнит 96×96 ×4 ракурса ×2 кадра · герой 128×128 ×4 ракурса ×3 кадра · портрет 512×512 · иконка UI/заклинания 64×64 · знамя 64×96 · катсцена 1280×720 (3 слоя для параллакса: фон/середина/фигуры отдельно!) · сплэш/биом-лоадинг 1920×1080 · карта-хаб 1920×1080.
**Серийность:** ассеты одного типа генерить одной серией с одинаковым промтом-каркасом; выбился из стиля → перегенерировать, не оставлять. Итог паковать в SpriteAtlas ≤4×2048², WebP/PNG-8, исходники сохранять в Art/Source.

## SKILL 3 — ГЕНЕРАЦИЯ ВИДЕО / КИНЕМАТИКОВ
**Когда видео:** трейлер игры (15–30 с), интро-ролики кампаний — если видеогенерация доступна в сессии.
**Когда параллакс-катсцена (по умолчанию):** все сюжетные вставки — 3-слойная иллюстрация + движение камеры в Unity Timeline (ТЗ №5 §8.7): дешевле, стабильнее, выглядит АА.
**Промт-шаблон видео:** «cinematic game trailer shot, {сцена из лора}, стиль референс-листа {N}, медленное движение камеры, без текста и логотипов, 24fps». Видео не должно содержать UI.

## SKILL 4 — КОД UNITY/C# (правила железные)
Чистый детерминированный Sim без UnityEngine · сцены/префабы только через Editor-скрипт FrontierBuilder (Tools→Frontier→Build All) · пакеты только из реестра Unity · uGUI+TMP по мокапам 1в1 · Input System (тач+мышь) · JSON-данные в Assets/Data + валидатор целостности на старте · ноль TODO/FIXME/alert/английских строк UI · каждая формула — из ТЗ №2/№5 дословно. Любой новый контент — данными, не хардкодом.

## SKILL 5 — САМОПРОВЕРКА ИСПОЛНЕНИЕМ (сдача без прогона = брак)
Перед каждой сдачей запускать у себя: EditMode-тесты математики (бой, EV ульт 400±10%, экономика, 8 инвариантов ТЗ №2 §13) · headless-бот миссий (цель: 22/22) · smoke Boot→Menu→партия 60 с→сейв/лоад · валидатор данных (каждая ссылка/спрайт существует) · Console: 0 красных. Выводы тестов вставлять в отчёт как текст, не как обещание.

## SKILL 6 — ЧТЕНИЕ РЕФЕРЕНСОВ (7 листов = библия)
Лист №1 цитадели LEVEL10 · №2 здания 4 ярусов · №3 библия (юниты 5+осада, биомы, события, узловое древо, мировая карта) · №4 герои (повороты+портреты) · №5 ресурсные карточки (8, описания дословно) · №6 UI-кит (терраны, дороги, профессии, заклинания 8, POI, приказы, декор) · №7 мокапы интерфейса (раскладка 1в1, армии-стеки, 3 карты, очередь строительства). Конфликт листов → канон-решения ТЗ №5 §1 и §1-Б; новое противоречие — решить самому в духе поздних листов и зафиксировать строкой в PROJECT_STATE.md.

## SKILL 7 — АУДИО
4 темы фракций + эмбиенты биомов + стинги (победа/поражение/ульта/эпоха): генерация музыки, если доступна; иначе процедурный синтез в WAV собственным скриптом. Чужие файлы запрещены. main_theme.mp3 — тема меню. Микшер: Music/SFX/UI.

## SKILL 8 — ПАМЯТЬ ПРОЕКТА (обязателен в каждом чате)
Вести файл `PROJECT_STATE.md` в корне проекта и обновлять КАЖДЫЙ спринт: версия/спринт · что готово (чек-лист систем) · канон-решения, принятые самостоятельно · известные хвосты с планом · следующая цель. Новый чат начинается с чтения PROJECT_STATE.md + этого файла + активного ТЗ — контекст не теряется никогда.

## SKILL 9 — СДАЧА
Каждый спринт: открываемый Unity-проект (ZIP без Library/Temp) + Builds (apk, exe по готовности) + README_UNITY.md + ОТЧЁТ.md по форме: «СПРИНТ N — СДАН / Сделано / Файлы / Тесты (вывод) / UI-аудит (экранов/элементов/дефектов) / Хвосты / Следующий шаг». Скрины экранов рядом с мокапами (визуальный дифф).

## SKILL 10 — БЫСТРЫЕ КОМАНДЫ ЗАКАЗЧИКА (реагировать без уточнений)
«U{N} пошёл» → выполнить спринт N ТЗ №5 · «аудит» → SKILL 5 полный прогон + отчёт · «перегенерируй {ассет} по листу {N}» → SKILL 2 серией · «дифф» → визуальный дифф экранов с мокапами · «сборку» → ZIP+APK немедленно · «состояние» → выдать PROJECT_STATE.md.
