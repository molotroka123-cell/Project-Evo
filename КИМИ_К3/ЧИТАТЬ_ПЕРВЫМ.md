## 2. ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ ПРО ИСХОДНЫЕ ТЗ

Оба файла с пометкой «исходное» приложены **для контекста, а не как задание**.
Они описывают другую игру и другую платформу:

- **ТЗ №5 требует Unity-проект.** Это решение было пересмотрено заказчиком.
  Игра сделана как браузерная и запускается двойным кликом по `frontier.html`
  без установки чего-либо. **Не переписывай на Unity или Unreal** без прямого
  указания заказчика.
- **ТЗ описывает фэнтезийный мир** с фракциями Люкс, Драк, Союз, Умбра, героями
  и ультами. В коде другая игра: историческая цивилизация от каменного века до
  Шпиля, 10 эпох, 8 фракций-соседей. **Не пытайся переделать одно в другое** —
  это переписывание с нуля, а оно запрещено.
- ТЗ упоминает мировую карту, достижения, юнитов на поле. **В игре этих экранов
  нет.** Проверено по коду рендера. Если решишь их делать — это новая работа,
  а не «доделать существующее».

Из этих ТЗ по-прежнему актуальны: требование русского интерфейса, запрет
заглушек и «потом доделаю», требование сдавать только с прогоном тестов,
а также подход «доказывай исполнением, а не обещанием».

## 3. Референсы визуального стиля

**Исходные арт-листы заказчика в архив не попали** — они присылались как
изображения в переписке и на диск не сохранились. Честно говорю об этом,
чтобы ты не искал их зря.

Чем это заменено:

- **`арт_промты_150.json`** — в каждом промте зашит стиль-якорь: камера
  (три четверти сверху, наклон 65°), свет (тёплый дневной сверху-слева 45°,
  сам источник в кадре запрещён), фон (плоская магента `#FF00FF` как хромакей).
  Этого достаточно, чтобы новый арт лёг в один ряд с уже сгенерированным.
- **`../shots/*.png`** — скриншоты игры как она выглядит сейчас.
- **`../art/raw/ИМЕНА.md`** — таблица соответствия сгенерированных картинок
  файлам игры.

**Сгенерированный арт (54 изображения)** лежит у заказчика двумя архивами.
Если их нет в `../art/raw/` — попроси заказчика приложить. Дальше:

```bash
node tools/art/cutout.mjs        # вырежет фон и разложит в app/assets/sprites/
```

Рендер подхватит спрайты автоматически: есть картинка — рисует её, нет —
рисует процедурно. Арт можно подвозить по частям.

## 4. Первое, что сделать, открыв проект

```bash
npm install
node app/tests/simtest.mjs      # должно быть 18 OK / 0 FAIL
node tools/build.mjs
```

Открой `frontier.html` двойным кликом и поиграй десять минут. **Не начинай
править код, пока не увидел игру своими глазами** — половина находок в этом
проекте была сделана именно так, а не чтением исходников.

Дальше — по `ПЕРЕДАЧА_КИМИ.md`, раздел «твой объём работ».
