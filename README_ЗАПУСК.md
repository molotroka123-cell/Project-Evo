# ФРОНТИР v2.0 — Руководство по запуску

**Жанр:** песочница-стратегия о развитии цивилизации — от первого костра (10 000 г. до н.э.) до Шпиля Цивилизации, уходящего в звёзды (2016+).

---

## 1. Запуск

### На компьютере (PC)
1. Скачайте файл **`frontier.html`** (один файл, ~1,5 МБ).
2. Откройте его двойным кликом в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. Интернет **не нужен** — игра работает полностью офлайн, прямо с диска.

### На телефоне
1. Перекиньте `frontier.html` на телефон (мессенджер, почта, кабель — любым способом).
2. Откройте файл браузером (Chrome / Safari). На Android файл обычно открывается прямо из «Загрузок»; на iPhone сохраните в «Файлы» и откройте оттуда.
3. Игра автоматически переключится в мобильный интерфейс: нижняя выдвижная панель, большие кнопки, управление жестами.
4. Совет: «Добавить на экран "Домой"» — игра будет запускаться как отдельное приложение на весь экран.

Звук и музыка включаются после первого касания/клика (требование браузеров).

---

## 2. Цель игры
Проведите поселение через **10 эпох** — от Каменного века до Будущего. Изучайте технологии (62), стройте здания (~55), кормите людей, защищайтесь от рейдов, торгуйте и договаривайтесь с соседями-фракциями. Финал — построить **Шпиль Цивилизации** (5 стадий). После победы доступны «песочница» и «Новая игра+».

## 3. Управление

| Действие | Телефон | ПК |
|---|---|---|
| Камера | свайп одним пальцем | ЛКМ-перетаскивание / WASD / стрелки |
| Масштаб | щипок двумя пальцами | колесо мыши / `+` / `-` |
| Выбрать / построить | тап | клик |
| Карточка здания | долгое нажатие | долгое нажатие ЛКМ |
| Подтвердить постройку | кнопка ✓ | ✓ / Enter |
| Отмена | ✗ | Esc / ПКМ |
| Пауза | кнопка ⏸ | Пробел |
| Скорость 1/2/8 | кнопки ▶▶▶ | клавиши 1 / 2 / 3 |
| Меню | кнопка ☰ | Esc |
| Консоль разработчика | тройной тап по значку эпохи | `~` / `ё` |

## 4. Сохранения
- Автосейв каждые 30 игровых дней + при закрытии вкладки (хранится в браузере).
- Меню → 3 ручных слота, **Экспорт** (файл .json) и **Импорт** — перенос мира между телефоном и ПК.
- Старые сохранения v1/v2 автоматически мигрируют в v3.

## 5. Советы новичку
1. Первым делом — **Хижина** и **Собиратели**: еда важнее всего.
2. Следите за вкладкой **Цели** — она ведёт по эпохам и выдаёт подсказки.
3. Запас еды на зиму: снег снижает добычу, люди едят больше.
4. Богатство привлекает рейды: стройте частокол и казарму заранее.
5. Соседи-фракции не читерят: с ними можно торговать, дарить золото, заключать договоры — или воевать.

## 6. Консоль (для экспериментов)
Нажмите `~` и введите `help` — список всех команд (give, spawn, research, simulate, godmode, faction и др.). Команда `simulate N` «перемотает» игру на N дней (не более 3650 за раз).
