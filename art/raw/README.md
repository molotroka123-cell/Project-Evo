# Сюда кладётся сгенерированный арт

Исходники из Higgsfield (Nano Banana Pro), как есть — с магентовым фоном.
Имя файла — идентификатор из `tools/art/prompts.json` (поле `file`), например
`campfire.png`, `hut.png`, `terrain/grass_summer.png`.

Обработка:

    node tools/art/cutout.mjs

Читает эту папку, вырезает хромакей-фон, обрезает по границам субъекта и пишет
готовые спрайты с прозрачностью в `app/assets/sprites/`.

Файлы, где в кадре нарисованы трава/небо/солнце вместо чистого фона,
помечаются в выводе как требующие перегенерации — их «чинить» нельзя,
нужно сгенерировать заново по обновлённому промту.
